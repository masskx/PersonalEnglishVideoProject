# 当前视频制作基准

版本：2026-10-14（纸面配色）  
适用范围：项目内所有英语视频与配套物料——四六级、考研英语、词根、词汇辨析、易混词、语法与日常用法；
主推 20–30 秒竖屏短视频（抖音、小红书发同一条）及其三张封面，另有用户要求时的长讲解横屏 / 竖屏成片。

## 这份文件的作用

这是项目唯一的视觉与成片基准。新会话、更换智能体、增加栏目或重做旧片时，先读本文件，再读根目录
`AGENTS.md`、`planning/production-defaults.json` 和相应 Skill。旧成片、旧版本规则和历史记录只用于追溯；
凡是与本文件冲突的旧说法（例如“纯白画布”“白底淡出”“背景必须 #FFFFFF”）一律以本文件为准。

用户后续明确提出的新要求优先；除此之外，不得回退到历史模板、旧动效或旧生图路线。

## 当前基准

- 配色基准：小红书词卡的纸面配色（2026-10-14 用户确认“以后都按这个配色”；图文卡本身已停用）。
- 短视频模板：`src/shorts/DouyinShort.tsx` + `src/shorts/ShortCover.tsx`（主推，见下文“短视频与封面”）。
- 长讲解模板：clud-clus（`src/replica/projects/cludClus.ts`，ten-tain 同款连续舞台 + 节奏闸门）。
- 小黑动作锚点：[mit / miss Sunburst](../references/visual-baseline/mit-miss-sunburst-full/mit-miss-sunburst-full.mp4)。

## 纸面配色（所有画面统一）

配色的唯一来源是 `src/replica/theme.ts`，所有渲染器（短视频、横屏、竖屏、封面、四六级课）都从这里取色；
不要在组件里另写底色。

| 元素 | 规则 |
| --- | --- |
| 画布 | 暖白纸 `#FFFBF3` + 浅色点阵（`#EDE4D3`，36px 间距，静止不动）。用 `paperStyle()`，不用纯白 |
| 主色 | 深蓝 `#041FA0`（标题、英文、正文强调）；橙 `#E85810`（词根、标签、行动号召）；深色正文 `#111111` |
| 词根重点 | 词根橙色 + 荧光黄色带（`#FFE36E`，文字下半部，`highlighterStyle()`） |
| 插图底板 | 小黑放在浅蓝圆角底板上（`#EAF0FF`，圆角约 40px）；同一框里的三态姿态共用一块底板 |
| 构词式 | “in- + clude” 用深蓝描边胶囊，后面跟灰色小字释义 |
| 例句 | 前面加橙底白字“例句”小标签，关键词橙色下划线 |
| 表格 / 总结 | 圆角描边卡片，行交替浅橙底（`#FFEEE2`），词根带荧光色 |
| 白底插图 | 少数 RGB 白底插图（四六级课）用 multiply 融进纸面，不能出现白色方块 |

词页（`<word>-word` 场景）的上述样式由 `src/replica/paperStyleStoryboard.ts` 在渲染时自动套用，分镜数据只写内容，
不用手写样式。

## 固定视觉规则

1. **生图**：使用内置 `image_gen` 生成真实栅格图。生成时用纯白背景（便于去底），输出透明 PNG；成片里插图放在浅蓝底板上。
   实心黑色小黑、实心白点眼、手绘抖线、少量橙红蓝教学色；小黑必须是语义动作的主角。先生成构图锚点，
   再从同一机位编辑 `before / change / result`。图片中不烘字、不用 SVG/代码几何图冒充插画，不用商业卡通、3D、
   素材拼贴或重复人物。插图在成片中必须 100% 不透明（小黑是纯黑，不是深灰）。
2. **素材复核（“白底复核”）**：指把插图单独放在纯白上检查角色本身——身体比例、实心白点眼、黑色手脚、冷静表情、
   有没有漂移。这只是检查插图的方法，**不代表成片用白底**；复核通过后再看纸面合成效果。
3. **基本套路**：前 1.5 秒给出具体问题或结果，3 秒内发生第二次画面变化；随后用一个可看懂的动作讲清知识点，
   加入例句、迁移或练习，结尾做可复述的总结。至少三种有教学意义的构图，文字与插图分区。
4. **节奏**：旁白里说到的例句、中文释义、搭配和对比都要在画面上出现（与旁白同时进场），不能只放在字幕里。
   `replica:validate` 的节奏闸门（`src/replica/pacing.ts`，字幕换句不算画面变化）：任何一段画面静止不超过 8 秒；
   超过 3.5 秒的静止合计不超过全片 20%；第一次画面变化早于 1.5 秒、第二次早于 3 秒。
5. **动画**：所有动效由 Remotion 帧驱动：平滑上移、滑入、遮罩揭示、词素组装（荧光色带随词根划出）、关键姿态切换、
   场景淡出到纸面；重点信息要有可读停留。禁止随机漂移、持续呼吸、乱跳、镜头抖动、整屏 SVG 机械层和每层一样的弹跳。
6. **字体**：主题字体是微软雅黑（Microsoft YaHei）。云端没有微软雅黑时用思源黑体（Noto Sans CJK SC）代替，
   标点必须是紧凑的中文全角标点，不能出现“include : 包含”这种松散标点。
7. **声音**：抖音节奏略快、明亮、有推进感；可听见的纯音乐（104–112 BPM），旁白期间自动压低，手机外放和耳机都必须
   听清人声。
8. **封面**：短视频每条三张，`ShortCover` 同一内容出三种尺寸——抖音竖封面 1080×1920（9:16，内容全部在中间
   1080×1440 内，电脑端裁成 3:4 也完整）、抖音横封面 1440×1080（4:3，左文右图）、小红书封面 1080×1440（3:4）。
   纸面底、浅蓝插图底板、荧光色重点词、橙色角标。长讲解沿用 `RootWordCover` / `RootWordLandscapeCover`。

## 短视频与封面（主推）

- 20–30 秒，1080×1920，抖音和小红书发同一条；一条视频一个文件夹 `outputs/shorts/<视频ID>/`，内含成片、三张封面、
  `publish.md`、`release.json`、`review/`。
- 结构（v2）：钩子 → 讲点（1–2 拍）→ 暂停作答（2 秒倒计时）→ 答案即结尾（答案拍叠收藏角标，不单独做收藏节拍）；
  旁白去掉首尾静音。钩子类型按发布顺序轮换：
  挑战题 → 常见错误 → 反差对比 → 结果先行，不做 A/B。
- 第一帧不淡入，直接有大字标题和小黑；每拍有画面变化（姿态切换、例句卡、错误划线、选项与倒计时）。
- 字幕与正文在抖音安全区内；插图复用来源期素材，需要新插图时按“生图”规则从已验收锚点编辑生成。
- 不再做小红书图文卡。

## 固定制作链路（长讲解）

`查重选题 → 登记制作中 → 资料核对 → 自然讲稿 → 复制 cludClus 模板建期 → 内置 image_gen 生图 → 素材白底复核 →
配音与混音 → validate（含节奏闸门）→ 完整渲染 → 整片预览 → 竖屏完整版 → 双封面与文案 →
音视频 / 内容验收 → 台账、日志和工作台更新`

一条命令交付：`npm run replica:produce -- --project=<期名> --stage=deliver`。

**竖屏**：由同一 storyboard、配音和插图重排为 1080×1920，不重新生图、不改讲稿；首帧即有题目和小黑，正文与字幕在
抖音安全区内（顶部 200px、底部 440px、右侧按钮列），结尾停在纸面总结页以便循环。行动号召与推广配置见
`planning/growth-promotion.json`。

每期运行时图片必须来自自己的 `public/assets/replica/<期名>/`；参考图只用于生成，不能跨期挂载。完整视频、双封面、
文案和检查记录进入 `outputs/<期名>/`。

## 最终整片闸门

最终渲染后打开 `review/full-preview/` 低清整片连续观看，并查看每页联系图，确认：

- 文字没有溢出、截断、错误换行或贴边；纸面底色和点阵一致，没有白色方块或白边；
- 小黑是纯黑、放在浅蓝底板上，文字与插画比例协调；
- 场景切换、关键姿态和文字动效连续；
- 手机尺寸仍能读清字幕、单词和重点；
- 背景音乐可听见但不盖人声。

自动检查（`verifyRender`、`verifyCover`）按纸面颜色 `PAPER_RGB` 检查画面四角；人工整片观看是最终通过条件。
只看中点截图不能代替整片预览。

低规格视觉链路、照抄 pon-pos / cred / duc-duct 等用 `'default'` 渲染的老期数。
