# 配音与绘图：目前项目怎么制作

更新：2026-09-29。项目整理保留现有成片、两种封面、配音和绘图源素材；新视频统一遵循
[当前视频制作基准](当前制作基准.md)。历史模型、旧试验和旧成片仅用于追溯，不再作为新片默认路线。
找作品从根目录 `PROJECTS.html` 进入，制作命令从 [README](../README.md) 进入。

## 1. 配音：阿里云百炼 CosyVoice

已逐一读取注册表中的 **17 期横屏项目配置**，目前的默认参数完全一致：

| 项目 | 当前设置 |
| --- | --- |
| 服务 | 阿里云百炼 / DashScope |
| 模型 | `cosyvoice-v3-flash` |
| 音色 ID | `longanhuan` |
| 项目历史配置 / 音高 / 音量 | `1.14` / `1` / `65` |
| 音频 | 分场景 MP3，44.1 kHz |
| 新合成默认 | 自然讲解模式，语速上限默认收至 `1.08`，启用短指令 |

台词写在 `src/replica/*Storyboard.ts` 等分镜文件中；音频放在 `public/assets/audio/replica/<期名>/`；每段文件的路径和时长记录在 `src/replica/*AudioManifest.json`。改一段台词可以只重新生成那一段，无需重做整期。

项目模块中的 `1.14` 是历史兼容配置；现在 `generateVoice.ts` 默认启用自然讲解模式：新生成音频默认不超过 `1.08`，并给 CosyVoice 发送“像真人老师讲短视频”的短指令。已有 MP3 不会自动替换，只有带 `--generate --force` 才会重新合成。可用 `REPLICA_TTS_NATURAL=0` 恢复旧行为，也可用 `REPLICA_TTS_RATE` 和 `REPLICA_TTS_INSTRUCTION_TEXT` 覆盖。现有音频清单只保存路径、时长，因此不能据此断言每个历史 MP3 都用完全相同的参数生成。本轮没有读取 `.env` 中的密钥值。

音频还有第二层速度控制：当一段配音长于分镜，Remotion 会加快播放；这是在合成语速 `1.14` 之外的调整。现有校验在播放倍率超过 `1.12` 时提示，超过 `1.16` 时失败。重新制作时应先缩短台词或延长分镜，再做成片校验。

背景音乐默认使用 `public/assets/music/root-word-series-bgm.mp3`，覆盖词根、四集系列和四六级视频；全片连续循环，备选音乐归在 `assets/music-source/candidates/`。代码音量系数平时为 `0.1`、有人声时降为 `0.045`，片头淡入 1.2 秒、片尾淡出 2 秒。成片校验会检查音轨、峰值不高于 `-1 dBFS`，以及未说明的长静音；最终仍需手机外放和耳机听审。

## 2. 绘图：内置 image_gen 栅格生图

新视频统一使用内置 `image_gen` 生成真实位图，风格以当前验收的 `mit/miss` 与 `ten/tain`
为锚点：纯白背景生成后去底为透明 PNG、实心黑色小黑、白点眼、手绘抖线、少量橙红蓝教学色；成片里插图放在纸面配色的浅蓝底板上（见当前制作基准）。小黑必须执行
能解释词义或考试技巧的动作，不能用 SVG、代码几何图、素材拼贴或文字烘在图里替代主插画。

制作顺序是：

1. 在项目分镜和提示词中先写清楚教学动作、构图和留白，再调用内置 `image_gen`。
2. 先生成构图锚点，再从同一锚点编辑 `before / change / result`；连续姿态保持机位、人物、
   道具、比例和方向一致。
3. 将通过白底角色复核的位图保存到 `public/assets/replica/<期名>/`，只允许本期素材进入渲染。
4. 在 Remotion 中负责文字、字幕、关键帧和纸面合成；最终检查主体比例、文字安全区和留白。

即梦/Seedream 生图、Wan 图生视频和代码绘制兜底图均已停用，相关脚本已在 2026-10-13 删除，新视频不得恢复。

封面会复用这一期的插图，标题和单词由代码排版。正式交付保留竖版 `cover.png`（1080×1440）和横版 `cover-landscape.png`（1200×900），与最终 MP4 放在同一期的 `outputs/` 目录内。

## 3. 同母版编辑链路（当前连续姿态默认）

2026-09-19：中转站配置已统一到项目根目录、被 Git 忽略的 `.env`。其中
`OPENAI_API_KEY`、`OPENAI_BASE_URL`、`OPENAI_IMAGE_MODEL` 和
`OPENAI_IMAGE_EDIT_MODEL` 由本项目直接管理，不再依赖其他项目的 `.env` 路径；文档、
计划和报告均不得保存 token。`/v1/models` 已重新验证可达，当前同时提供 `gpt-image-2`
和已获用户确认的 `gpt-image-2.5-sunburst`。

新的一次性母版图通过内置 `image_gen` 生成；需要同一小黑、机位和道具连续的动作姿态时，
使用已配置的图像编辑接口从同一母版分别编辑 `before / change / result`，不把上一张编辑结果
继续串联下去。
已确认的视觉金样保存在 `assets/visual-baselines/mit-miss-sunburst/`，包括参考图、结果图、
并排对比、实际提示词和不含凭据的调用报告。

接口可能把请求的 `1536x864` 或 `2048x1152` 返回为其他实际尺寸，因此所有结果都要
归一化到项目画布所需尺寸，再执行透明度、主体占比、边缘、白底复核和纸面合成验收。
通用计划入口为 `scripts/replica/generateReferenceKeyPoses.ts`，示例计划是
`planning/visual-baselines/mit-miss-sunburst-plan.json`。

## 4. 小黑为什么会动

现行默认方式是**参考图编辑的静态关键姿态，加 Remotion 局部关键帧动画**。小黑、道具和重点文字只在讲到“送入、弹出、横跨、打断”等语义动作时发生短距离位移、缩放或轻微回弹，不再用持续漂浮和整页缓慢平移掩盖静止。右上章节徽章、大号根词水印以及覆盖插图的全画布 SVG 机械/轨迹层默认关闭；需要时必须由项目配置显式打开。Wan 图生视频路线已停用。

`ject` 的专用画面，以及 `dict`、`script-scrib`、`tract`、`form` 的部分场景仍引用早期生成的动态图片序列（`public/assets/replica/*-motion/`），只用于重渲染这些旧期，不再为新期生成。

## 5. 常用操作：先看清单，再按需生成

从项目根目录运行，把 `<期名>` 换成注册期名，把场景 ID / 图片 ID 换成清单中的真实值。

| 操作 | 命令 |
| --- | --- |
| 查看配音计划，不调用接口 | `npm run replica:voice -- --project=<期名>` |
| 生成缺少的配音 | `npm run replica:voice -- --project=<期名> --generate` |
| 重做一段配音 | `npm run replica:voice -- --project=<期名> --scene=<场景ID> --generate --force` |
| 查看绘图提示词，不调用接口 | `npm run replica:images -- --project=<期名>` |
| 测试 Images2 中转图，不重复生成 | `npm run replica:image:test -- --reuse-source` |
| 查看参考图编辑关键姿态计划 | `npm run replica:keyposes:edit -- --plan=<计划JSON>` |
| 生成参考图编辑关键姿态 | `npm run replica:keyposes:edit -- --plan=<计划JSON> --generate` |
| 只重做一个姿态 | `npm run replica:keyposes:edit -- --plan=<计划JSON> --generate --only=<动作ID> --pose=<状态ID> --force` |
| 生成缺少的图片 | `npm run replica:images -- --project=<期名> --generate` |
| 重做指定图片 | `npm run replica:images -- --project=<期名> --only=<图片ID> --generate --force` |
| 检查音频与分镜时长 | `npm run replica:validate -- --project=<期名>` |
| 检查最终视频音轨、峰值等 | `npm run replica:render:verify -- --project=<期名>` |

默认生成会复用已有素材；`--force` 会替换所选素材。绘图的 `--only=` 支持逗号分隔多张图。`--reprocess` 可以重做本地去底，但必须与 `--generate` 同用，而且在缺少原图时仍可能调用接口，不能当作完全离线命令。
