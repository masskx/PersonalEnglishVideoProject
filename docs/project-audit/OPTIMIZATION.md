# 项目现状与后续优化路线

整理日期：2026-09-11。依据为当前源代码、17 期交付文件、现有原型、项目技能和历史记录。以下对重复感的判断来自内容结构与抽样画面；未接入账号后台，也没有播放、完播、涨粉数据，因此不把结构相似直接解释成流量下降。

## 已经积累下来的东西

你已经有一套可复用的制作基础：小黑角色、白底蓝橙视觉、即梦/Seedream 插图、百炼配音、音频混合、字幕、Remotion 动画、两种封面、发布文案，以及技术检查。后续最值得保留的是这些稳定能力。

现有内容覆盖 press、reg、fer、bouba-kiki、ject、port、spect、vis-vid、aud、dict、script-scrib、tract、form、struct、flect-flex、rupt、mit-miss。大部分讲词根/词族，bouba-kiki 讲语音象征。

当前共 20 个 Remotion 合成项：17 期长视频、2 个共享封面组件、1 个短视频原型。长视频有成熟产物，短视频还有 5 张占位图和内容硬编码，二者完成程度不同。

## 把现有模板当作一个栏目继续使用

建议暂时沿用“小黑英语”这一类统一角色识别，把“小黑拆词根”保留为现有长栏目。名称这里只是层级示意，不是在本轮改账号名。

先探索三类栏目已经足够，避免一次维护太多模板：

| 栏目方向 | 观众得到什么 | 一条内容的推进方式 | 可复用资产 |
| --- | --- | --- | --- |
| 小黑拆词根：系统复习 | 看懂一组词的关联 | 一个核心概念 → 少量代表词 → 应用 → 复习 | 现有 17 期、地图、语义动作、封面 |
| 小黑遇到事：情境单词 | 知道什么时候说一个词 | 冲突发生 → 猜词 → 单词揭示 → 一句可用表达 | interrupt 原型、百炼音频时间线、小黑 IP |
| 小黑二选一：易混词 | 在相近词里做正确选择 | 同一场景两种结果 → 观众选择 → 对比反馈 → 再测一次 | 测验组件、对比图、字幕和例句 |

时长可以先以情境 18–30 秒、对比 25–45 秒、长栏目按内容确定作为实验范围。这是后续设计建议，尚未修改现有 1920×1080 母版、旧作品时长或全系列规范；短视频原型当前硬限制仍为 15–28 秒，扩展时需同步修改。

## 建议的第一轮样片

优先用已经有基础的 interrupt / disrupt 主题验证三个结构，先只做本地试片：

1. **情境版**：完成现有 interrupt 的五张关键帧，让“说话被插入打断”一眼可见。保留真实配音时间线，输出完整竖屏样片。
2. **对比版**：同一个会议场景，一次是某人插话，一次是现场秩序被搅乱。分别对应 interrupt / disrupt 的该场景用法，补充自然例句，并避免把二者全部词义简化成绝对二分。
3. **挑战版**：先给场景和选择，让观众作答，再用动作揭示原因。开头与结尾都围绕判断，减少连续解释。

三版尽量复用角色、音色和主题，方便比较“结构变化”是否带来更明确的体验差异。第一轮不需要更换所有美术风格或为 17 期重做动态视频。

完成前先检查：不开声音是否看懂冲突；前 2–3 秒是否有具体问题；单词出现时是否解释得通；末尾是否能说出一句话或作出一次选择。后续发布比较可人工记录平台提供的停留/平均观看/完播、收藏和评论内容，并注明时长与曝光量差异。小样本只作方向参考，本轮未自动收集数据，也未建立定时监控。
