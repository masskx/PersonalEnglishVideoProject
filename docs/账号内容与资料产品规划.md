# 小黑英语：从词根栏目到四六级学习资料

当前目标是把小黑英语视频做成可靠、易懂、可持续生产的栏目，覆盖词根和四六级备考。
账号面向基础一般、需要具体练习步骤的大学生：视频解决一个问题，资料帮助重复练习。
词根是入口栏目，最终产品价值来自正确的解释、练习、反馈和可复用的学习方法。

## 账号统一主线：小黑陪你把英语弄明白

栏目可以多元，但不把账号做成互不相关的英语知识合集。统一识别点是“小黑遇到一个真实的英语问题，先犯难或做动作，再把规律讲明白，最后给观众一个能马上做的小练习”。

- 小黑是每期的叙事主角，不只是角落里的装饰；动作要解释词义、句型关系或做题步骤。
- 画面统一使用当前制作基准：内置 image_gen 栅格生图、白底小黑、蓝橙信息色、手绘线条、
  语义关键姿态、丝滑帧动画、共享封面和整片预览；阅读、写作、翻译可以按教学任务调整构图。
- 配音采用略快、明亮、有推进感的抖音节奏，同时保留短停顿、追问、纠正和轻微口语化，不连续堆定义。
- 每个栏目都要有“视频学会什么”和“资料可以反复练什么”的一一对应关系，先积累信任，再验证资料需求，不提前承诺变现结果。

## 四类内容分别怎么讲

| 栏目 | 视频结构 | 对应资料 | 观众学会什么 |
| --- | --- | --- | --- |
| 词汇 | 情境问题 → 词素 → 动作结果 → 搭配/例句 → 自测 | 复习卡、间隔复习表、近义辨析题 | 在新句子里识别并使用词义 |
| 易混词辨析 | 小黑先选错 → 对比最小语境 → 替换测试 → 一题自测 | 易混词对照表、语境选择题、错因卡 | 说清两个词何时不能互换 |
| 阅读技巧 | 先选答案 → 找定位线索 → 对照原句 → 同义替换 → 排除干扰项 | 定位与排除训练单、逐项解析 | 说出正确项与错误项的文本依据 |
| 写作 | 弱句 → 问题 → 修改依据 → 情境替换 → 小练习 | 场景句型库、可编辑写作框架、示范与禁用情况 | 为具体题意组织论证，不生搬套句 |
| 翻译 | 中文断句 → 找主干 → 处理修饰 → 重组 → 对照误译 | 分层练习、参考译文、常见错误表 | 保留信息并写出自然英文 |

新栏目继承当前制作基准的生图、声音、字体动效、双封面和整片预览规范；版式应按题目证据、句子修改或翻译对照重新设计。
不是每一页都需要小黑占半屏，也不要求阅读题变成词根卡片。
真题必须记录年份、考试级别、套卷、题号、来源、原文与答案核对依据及使用权限。
未获得可靠来源时使用明确标注的原创模拟题，不把自编题称作真题。

## 第一份产品怎么做

建议先做“小黑词根复习与自测”小样：从已复核的一期开始，给出词素关系、
常用搭配、3–5 道自测及逐题解析。配可打印 PDF 与可编辑模板，提供一页使用说明。
先看学生能否独立完成、解析是否解决疑问，再决定扩充哪几期。

后续可分别形成阅读训练、写作框架、翻译练习产品；先分清使用场景，再考虑组合包。
产品说明必须列明适用基础、内容目录、格式、示例、版本、更新范围、交付方式、
支持渠道与退款规则。售价待样张反馈、制作/支持成本及实际需求确定，不虚构收入预期。
出售的是整理、练习设计和解析价值，不承诺保过或靠万能模板拿高分。

视频中的下一步先指向与本期直接相关的练习；资料页展示可读样张和使用方式，
再说明完整包提供什么。平台发布、商品上架和对外发送另按实际授权执行。

## 每周如何管理

打开根目录 PROJECTS.html：上方推进计划，下方查找已有视频与双封面。
阶段用“选题 → 脚本 → 制作 → 审核 → 待发布 → 复盘”。进入审核须有视频、
双封面、发布文案和检查单；真正发布后另维护 release.json 和平台链接。
计划阶段不等于发布证据。历史 4 处冲突继续保留，需据平台实际情况核对。

每次工作结束写清下一步；每周导出计划 JSON。浏览器改动存在 localStorage，
不会写回 planning/content-plan.json。换浏览器需导入备份；要让其他设备/重新生成页面
继承计划，可将审核过的导出 JSON 更新为该源文件，再运行 npm run project:inventory。
刷新只重建页面，当前浏览器已有记录仍优先显示；要采用新源计划，可导入该文件。

## 复盘与决策

所有新数据留空，实际发布后才填。统一窗口，例如发布后 7 天，并保留平台记录。

- 内容：播放数、平台完播率、收藏数、评论中的具体学习困难。
- 资料：资料页点击、付款订单、退款订单、净实收；记录交付与支持耗时。
- 收藏率 = 收藏 / 播放；资料页付款转化 = 付款订单 / 资料页点击。
  分母为零或口径不同则不计算；订单与点击要同来源、同统计窗口。
- 净实收不是利润，利润还要扣平台费用、生成与制作成本、售后等。

观看弱但收藏高：先调整开头和表达密度；点击高但付款低：检查样张、用途与定价；
付款后退款高：优先修复预期和交付质量。没有数据时保持“待验证”，不预填成绩。
