# 成片交付目录

本目录只存放最终视频及与其直接相关的验收产物。每个子目录对应一条视频。

| 子目录 | 最终视频 | 统一封面 |
| --- | --- | --- |
| `press/` | `press.mp4` | `cover.png` |
| `reg/` | `reg.mp4` | `cover.png` |
| `fer/` | `fer.mp4` | `cover.png` |
| `bouba-kiki/` | `bouba-kiki.mp4` | `cover.png` |
| `ject/` | `ject.mp4` | `cover.png` |

新增视频统一使用 `outputs/<slug>/<slug>.mp4`，并在同一子目录保存统一封面
`outputs/<slug>/cover.png`。不要在根目录、`edit/` 或 `out/` 另建成片或封面。
