# 新视频标准提示词

复制下面内容，把尖括号中的信息替换后发给 Codex：

```text
请使用 build-root-word-video Skill，在当前项目中制作一条新的白底小黑词根讲解视频。

词根/主题：<必填，例如 spect>
核心含义：<必填，例如 看>
必须讲解的单词：<必填，例如 inspect, respect, suspect, prospect, spectator>
每个单词的中文义项或例句：<可选；没有则由你核对并编写>
记忆钩子：<可选；没有则由你设计>
目标时长：<可选，例如 90-120 秒；没有则按内容决定>
结尾压暗：<全黑 / 部分压暗 / 不压暗；没有则按节奏决定>
参考样片：<可选，填写本地路径；没有则沿用当前系列风格>

制作要求：
1. 画布严格使用 #FFFFFF，1920×1080，30fps。
2. 字体使用系统微软雅黑；主色 #041FA0，强调色 #E85810。
3. 所有插图必须遵循项目中的小黑黑线风格：黑色实心小黑、两颗白点眼、细四肢、
   冷静表情，并由小黑执行每个场景的核心动作。
4. 生成插图时使用纯绿背景并代码抠图；模型提示词中不要写艺术家名字，避免签名。
5. 文字、箭头、括号、图标、表格和总结页由代码绘制，不要烘焙进插图。
6. 请自行完成详细文案、Storyboard、配音、动画、转场、字幕、总结表和结尾设计。
7. 检查语速、长静音、音频峰值、白底、边界帧、透明素材绿边和完整音视频解码。
   每次草稿和正式渲染都必须自动加入项目统一背景音乐；旁白期间压低音乐，首尾淡入淡出。
8. 有样片时生成同时间点对比联系表并迭代；没有样片时沿用现有项目的节奏语言。
9. 最终成片、报告、对比和抽帧统一放在 outputs/<slug>/。
10. 同时使用项目统一的 React/Remotion 封面组件生成 1080×1440 的 cover.png：纯白底、
    微软雅黑、深蓝/橙色、固定品牌栏和版式，小黑主题动作位于固定中右区域，底部列出
    词族并突出共同词根。优先复用成片已验收插图，缺少时再用即梦生成并抠图。
11. 更新该视频 README、docs/production-log.md 和 PROJECT_MEMORY.md。
12. 除非缺少身份关键或授权素材，否则不要中途询问，直接完成并验收。
```
