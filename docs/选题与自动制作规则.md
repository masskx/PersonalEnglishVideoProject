# 选题与自动制作规则

来源：用户于 2026-09-12 明确要求。适用于本项目后续所有智能体与新会话，
除非用户后来给出不同要求。项目根目录 AGENTS.md 是发现入口。

视觉与交付规则以[当前视频制作基准](当前制作基准.md)为唯一准绳。下面的选题规则只决定
讲什么，不允许把任何栏目降级为旧版 PPT 卡片、旧生图接口、简化封面或没有整片预览的试片。

## 怎么理解制作请求

| 用户请求 | 执行动作 |
| --- | --- |
| “做一个词根视频” | 自主寻找适合系列的新词根，查重后直接制作完整视频 |
| “做一个词根辨析/易混词视频” | 视为只指定栏目；自主选择未做过的辨析主题，查重后复用当前小黑完整链路制作 |
| “做一个四级作文讲解视频” | 自主寻找未讲过的题目/核心讲解点，查重后直接制作 |
| “做一个阅读定位/翻译拆解视频” | 自主确定一个可带走的技巧与练习材料，查重后直接制作 |
| “做 spect 词根”“讲这道作文题” | 按指定题目或材料执行；做过则保留旧版并制作本次版本 |
| “看看这个选题”“帮我记录规则” | 完成讨论或记录，不擅自开始生产视频 |

“直接制作”包含必要的资料核对、脚本、已配置配音与画面流程、渲染、视频与双封面、
文案、验收和项目登记。普通选题不需要用户批准；只有任务关键材料确实无法获得或
存在无法合理解决的歧义时，才提出具体问题，同时继续不依赖答案的工作。

## 未指定题目时复用什么链路

“复用之前的链路”指复用已经确认的制作方法和质量门槛，不是机械复制某一期版式：

1. 先识别栏目，再查 `topic-history.json`、正式成片、草稿和试验，自动选择未做主题。
2. 所有栏目默认复用当前验收的小黑链路：内置 image_gen 栅格生图、固定母版，编辑
   before/change/result 语义姿态，以局部关键帧和丝滑文字承担运动，不使用遮挡主体的
   全画布 SVG 机械层。词根、词汇辨析、四集系列和四六级视频都必须遵循同一视觉、声音、
   封面和整片预览标准。
3. 写作、阅读、翻译可以按教学任务调整分镜顺序，不把词根拆词版式硬套过去；但必须保留
   同一小黑身份、白底画布、image_gen 画面、丝滑文字、可听见且压低的背景音乐、共享封面
   母版和整片预览闸门。
4. 默认完成两分钟以上的有效教学、练习与讲评，并交付 MP4、双封面、发布文案、必要
   配套资料和检查记录。
5. 完成后更新主题台账和制作日志，刷新工作台；当前交付进入首屏，过程材料进入收起的
   历史与技术档案。不得只留下聊天结论或藏在试验目录中的视频。

## 自主选题怎么找

先确定用户指定的栏目；根据现有系列和四六级学习需求，自主检索、筛选合适题目。
已有待做计划可以作为候选，不能把“计划过”误判成“已经制作”。
优先选择能解决一个明确学习问题、事实可靠、可用例句/画面解释、难度适合观众的内容。
资料查证使用可靠词典、教学资料或可核对的试题来源；在分镜或选题记录中保留来源。

用户未要求真题时可以使用清楚标注的原创模拟题。用户明确要求真题时，必须找到并
记录真实年份、级别、套卷/题号及来源，不能把原创题冒充真题。查不到可靠材料则
说明具体缺口，不虚构题目来源。词根解释区分真实构词与记忆联想。

## 查重范围与判定

制作前交叉检查，不能只看“已发布”或某一份列表：

1. planning/topic-history.json：长期主题台账，含已有作品与在制题目。
2. src/replica/projects/registry.ts、src/cet-*、src/cet6-* 各栏目数据与 docs/project-audit/inventory.json（`npm run project:inventory` 生成）。
3. outputs/ 中的真实交付；本机 work/ 里正在进行的草稿（work/ 不进 git）。
4. planning/content-plan.json、PROJECT_MEMORY.md、docs/production-log.md。

台账之外发现历史制作，先补登记再选题。查重覆盖当前项目可核对的历史；没有证据
时不声称已查过外部账号或其他机器上的全部内容。

- **词根**：统一大小写、连字符和常见变体。同一词根家族算同题，例如 mit/miss、
  vis/vid、script/scrib、flect/flex；不能拆开别名假装新主题。
- **词汇单题**：同一目标词和核心讲解视为重复；新词根视频中偶然出现以前讲过的
  某个单词，不自动等于整个主题重复。
- **作文、阅读、翻译**：同时比较题目/材料和核心教学点。只换例句、标题或画面，
  仍然讲相同内容，不作为自主选题的新一期；同一栏目采用新的实质教学目标则可以。
- **草稿和试片**：已经开始制作或存在实际产物就算占用，不要求发布成功。
- **修订版**：同题重绘、改动效、重新剪辑归入原主题的版本列表。

## 登记与完成

自主选题查重通过后，先在台账追加 stable id、栏目、题目、归一化别名、核心教学点，
将状态设为 in_progress，并记录查过的范围和选题依据。恢复在制项目时继续原条目，
不要新建重复主题。完成后改为 produced，添加实际产物路径；produced 仅代表存在
交付，不代表内容已审核、已发布或已卖出。

若中途停止，保留状态与原因。用户指定重复题时记录 requestedByUser 和新版本，
不覆盖原成片，不把本次修订登记成一个自动选出的新主题。
自动清单刷新不能清空或覆盖人工维护的主题台账。浏览器 localStorage 不作为唯一历史。

台账记录全部词根期与四六级期数；mit/miss 的关键姿态与流畅文字试验作为同题版本记录。
2026-10-13 删除了 interrupt 竖屏原型等旧试验，台账里的旧路径只作追溯。

## 全栏目默认制作标准（2026-09-13）

- 默认完整视频时长超过 120 秒，优先约 2–3 分钟；用户明确要求短片时按指定时长。用讲解、辨析、迁移练习和讲评增加有效内容，不靠放慢语音、空白停顿凑时长。
- 偏向四六级应试，但保持易懂、有趣。每期聚焦一个可带走的小知识点、小模板、技巧或方法：明确问题，演示用法，安排小练习，解释答案与使用边界。不承诺分数或把一种结构称为万能模板。
- 所有栏目默认使用丝滑文字动效、合理关键帧与连贯进出场，无需用户每次提醒；动效服务理解，英文留足阅读时间。
- 正片只出现对观众有用的标题、例句、讲解重点与字幕。删除右上角步骤导航、制作流程标签、调试小字、冗余脚注和无教学价值的旁注。必要题目来源保留在题目页，详细来源放交付说明。
- 新人只需打开根目录 `00-打开工作台.html`。最新完整交付放 `outputs/`，工作台首屏列出成片原文件、双封面、可直接复制的文案及发布平台入口；不要仅交付藏在试验目录里的链接。
- 有实质歧义、无法合理决策时，提出具体问题与用户沟通；已明确的默认偏好和普通实现选择直接执行。
