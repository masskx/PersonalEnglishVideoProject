# 新会话制作入口

本文件用于新窗口、新任务或更换智能体后恢复项目规则，不依赖历史聊天记录。

第一优先级是[当前视频制作基准](当前制作基准.md)。它定义所有栏目共同的画面、动画、声音、
封面和整片预览标准；历史成片和审计快照不覆盖它。

## 新智能体的第一步

1. 完整读取 `docs/当前制作基准.md` 和根目录 `AGENTS.md`。
2. 读取 `planning/production-defaults.json`，确认当前链路和视觉基线。
3. 读取 `docs/选题与自动制作规则.md`。
4. 制作请求加载 `.agents/skills/make-xiaohei-english-video/SKILL.md`；词根、词汇辨析、
   易混词等再加载 `build-root-word-video/SKILL.md` 及其相关参考。
5. 查 `planning/topic-history.json` 和实际 `outputs/`、`work/drafts/`、
   `work/experiments/`，不能只相信浏览器缓存或聊天摘要。

## 判断用户有没有指定题目

下列属于“已指定题目”：

- “做一期 spect 词根。”
- “做 affect 和 effect 的辨析。”
- “用这道四级题讲阅读定位。”

下列属于“只指定栏目，未指定题目”：

- “做一个词根视频。”
- “做一个词根辨析视频。”
- “做一个易混词视频。”
- “做一期四级写作、阅读或翻译视频。”

前者严格按指定内容制作；后者自主查重选题并直接完整制作，不要求用户从候选中选择。

## 当前默认制作链路

`识别栏目 → 查重选题/接受指定题目 → 登记制作中 → 资料核对 → 自然口语讲稿与配音 →
内置 image_gen 生图与白底复核 → 同母版 before/change/result 语义姿态 → 丝滑文字关键帧 →
完整渲染 → 整片低清预览与安全区/留白检查 → 音视频与内容检查 → 双封面/文案/配套资料 →
更新台账与日志 → 刷新工作台`

所有栏目统一参考当前制作基准和 `mit-miss-sunburst-full` / 最新验收成片的视觉方法；写作、
阅读、翻译只根据教学任务调整内容结构，不另起低规格模板。禁止因为用户没给具体题目，就把
视频降级成静态卡片、PPT 念稿、无练习短片或只有制作计划。

词根制作要先建立“每个教学词 → 独立意思/动作 → 本词 before/change/result 素材 → 总结行”的
完整映射。先运行词图计划预检，再生成和白底复核素材，再运行完整预检；失败时不得进入配音和渲染。
每期运行时图片必须来自本期自己的 `public/assets/replica/<episode-slug>` 目录；旧图只能作为
生成参考，不能直接挂进新片。计划要记录 asset provenance，渲染前来源扫描会拦截跨期路径。
渲染脚本自动收集本期实际引用的公共素材，避免复制整个历史素材库。

## 交付和工作台

- 当前可用成片、双封面和文案进入工作台首屏。
- 历史视频、接口测试、参考图和姿态证据进入默认收起的档案。
- 中间装配目录保留在 `work/`，不在工作台冒充成片。
- 完成制作不等于发布；不自动上传平台。

运行 `npm run project:check` 可以检查本入口、总制作 Skill、机器默认配置和视觉基线是否
仍然存在。
