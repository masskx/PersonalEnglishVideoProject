# 交付与发布记录

现行完整流程见 [项目管理流程](项目管理流程.md)。日常入口为 [项目管理页](../PROJECTS.html)。

- 成片、双封面、文案：outputs/<期名>/ 或 outputs/<期名>发了/。
- 草稿：work/drafts/<期名>/draft.mp4。
- 验收图片/分镜：各期 review/；新抽帧默认 review/stills/。
- 原型：work/experiments/meme-vocab/interrupt/。
- Wan 历史源片和任务：work/experiments/wan-history/。
- 运行时音频、插图、序列帧：public/assets/，继续保留。

所有长视频命令通过共享路径解析识别现有目录；同时存在普通/发了目录时停止，不自动合并。
发布记录命令不上传平台。4 处历史状态冲突见当前清单，等待事实核对。
