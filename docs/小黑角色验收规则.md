# 小黑角色验收规则

适用于词根视频和后续所有复用小黑 IP 的新视频。角色是资产的第一道门，不通过角色复核，不进入配音、时间轴和成片渲染。

本文的“白底复核”是把插图单独放在纯白上检查角色本身；成片底色是纸面配色（暖白点阵纸 + 浅蓝插图底板，见当前制作基准），两者不冲突。

## 角色锚点

- 新图必须先参考项目内已接受的小黑素材与 `references/ian-xiaohei/` 样例；通用的“black bean / stick figure”描述不能单独作为角色依据。
- 小黑应是画面中的主要语义演员：较大的厚实黑色不规则主体、稳定的白色实心圆点眼睛、可读的黑色手臂和弯曲腿，认真完成一个荒诞但清楚的动作。
- 角色身份优先于道具。道具可以换，身体比例、眼睛形态、黑色轮廓重量和冷静表情不能无故漂移。

## 生成顺序

1. 先选一张项目内正式素材做角色锚点，写清楚“保持不变”的身体、眼睛、比例和线条。
2. 只为一个动作生成一张母版，先在纯白底上检查，再从母版编辑其他语义姿态；禁止先批量生图再挑一个像的。
3. 生成后必须做白底合成复核。透明图在黑色预览背景上容易掩盖黑色主体，不能只看透明预览。
4. 角色复核通过后才复制到 `public/assets/replica/<slug>/`，再继续配音和渲染。

## 立即拒绝

- 身体缩成小黑点或细长火柴人；手脚只有头发丝般的线；眼睛变成空心圆环。
- 小黑只是站在道具旁边，去掉小黑后核心动作仍完全成立。
- 多余角色、额外手脚、服装、可爱表情、商业卡通、3D、PPT 图表或背景场景。
- 白底合成后主体比例、方向和接触关系不清楚，或道具遮住小黑的动作。

## 记录

每期把角色锚点、白底复核图、通过/淘汰说明和最终采用的姿态来源记在交付目录 `review/` 与关键姿态计划（`planning/<slug>-keyposes.json`）里；淘汰图只放本机 `work/`（不进 git），不能留在运行时素材目录，也不能被工作台当作交付展示。
