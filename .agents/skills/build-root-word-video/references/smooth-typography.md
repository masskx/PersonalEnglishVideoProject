# 静态配图与流畅文字

当用户要求关键帧更丝滑、剪映式文字动作或更自然的节奏时，使用本参考。
配图继续按 key-pose-storytelling.md 表达因果，文字独立编排动作。

## 可复用动作

实现位于 src/replica/smoothMotion.ts 与 visuals.tsx；配置见 types.ts。

| 内容 | 配置 | 起点建议（30 fps） |
| --- | --- | --- |
| 普通标题 | enter: smooth-rise | 16px 上移，16 帧进入 |
| 解释或公式 | enter: smooth-slide | 24px 横移，16 帧进入 |
| 释义、例句 | enter: smooth-reveal | 底部遮罩展开，16 帧进入 |
| 彩色词素组合 | runMotion: assemble；enter: none | 原 runs 分组，55ms 错峰，480ms 归位 |
| 教学文字退出 | exit: smooth-out | 10px 上移，10 帧退出 |

位置使用五次平滑曲线，起止速度和加速度均为零；不使用 CSS animation、
transition、墙钟或随机数。时长字段小于 2 为秒，其余为帧；当前进入限制 8–18 帧，
退出限制 6–10 帧。所有动画由 Remotion 帧索引驱动。

## 编排原则

- 开场第一帧有可读问题，避免所有元素一起从透明状态开始。总览、例句、总结等
  新页的首标题立即可读；纯文字页在退出时保留首标题，避免页面边界白闪。
- 先词形，再拆解，再在语义结果处揭示释义。沿用配音节拍，不能为了错峰任意错开讲解。
- 词素组合只用于短单词；保持最终字距，不逐字旋转、弹跳或打散长句。
- 一个信息块只用一种主要进入动作。文字的可读停留时间不应被长动画吞掉。
- 固定配图直接换态；禁止把整张小黑图拖动来模拟身体动作。文字退出时配图仍可读，
  不以整屏白闪、强模糊或连续缩放掩盖交接。
- 当前实现是剪映常见滑入、遮罩揭示、组合归位的视觉原理；没有指定参考时，
  不宣称复刻了某个剪映预设。跨单词共享词根位置的变形需要独立设计，不能叠出错误词形。

## 验收与复用

先渲染包含单词退出和下一个单词进入的短片，检查动作中间帧、交接前后帧、
最终稳定字距、中文裁切与图文遮挡，再渲染整期。静帧不能证明主观流畅性，
仍须实际播放复核。保存原版、上一次试验和新试验，未通过感官复核不改正式发布状态。

本项目实例：npx tsx scripts/replica/smoothTrial.ts，输出
work/experiments/mit-miss-smooth/props.json。该脚本不请求配音或生图接口。
按此模式生成新一期时显式选择上述动效，不批量改写历史项目的默认效果。

## 跨栏目复用与资料产品

账户规划见 docs/账号内容与资料产品规划.md，计划源在 planning/content-plan.json。
阅读技巧、写作、翻译和四集系列可以使用自己的讲解结构，不能强套“词根拆解 + 小黑动作”；
但它们必须继承当前制作基准的 image_gen 栅格画面、白底小黑、品牌色、文字动效、纯音乐混音、
双封面和整片预览闸门。
每个试点记录学生问题、可验证学习结果、练习/模板用途、来源与审核状态。
计划状态、平台发布证据和销售数据分别维护，不因渲染完成自动标记发布或变现成功。
