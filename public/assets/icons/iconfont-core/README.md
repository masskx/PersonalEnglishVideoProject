# Iconfont Core

Small local SVG reference library captured from the public Iconfont search interface.

## Rules

- Treat every file as `reference-only-until-license-reviewed`.
- Before publishing an icon in a video, open the recorded source URL, identify the author or
  collection, and confirm its current license permits the intended distribution.
- Do not assume that public search visibility means unrestricted commercial use.
- Prefer a semantic Xiaohei action or a code-drawn teaching diagram when it explains the idea
  better. Do not add an icon only to fill white space.
- Keep icons in the series palette: deep blue `#041FA0` and teaching orange `#E85810`.
- Animate only a meaningful property: path draw, focus pulse, reveal, or state change.

`manifest.json` records the Iconfont ID, SVG hash, search URL, and retrieval date for each file.
