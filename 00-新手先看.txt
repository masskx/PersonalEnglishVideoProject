[English]
1. Double-click "00-打开工作台.html" (the workbench). No coding tools needed.
2. Pick an episode in the first section, play or save the MP4.
   Each episode folder in outputs\ also has: vertical\ (Douyin vertical cut, teaser, recap card)
   and xiaohongshu\ (3:4 image cards + xhs-note.md).
3. Save the two covers, copy the publish text, upload by hand on Douyin / Xiaohongshu / Bilibili.
4. To make a new video with local Codex, read docs\LOCAL-CODEX-QUICKSTART-EN.md and
   docs\CODEX-PROMPT-GUIDE-EN.md. Codex reads AGENTS.md automatically.

Folders: outputs = finished deliveries. src, scripts, public, assets = production code and art.
work = local scratch (not in git; safe to empty). Old trials were deleted on 2026-10-13; git history keeps them.

[中文]
1. 双击「00-打开工作台.html」。无需启动编程工具。
2. 首页选一期，播放或保存 MP4。每期 outputs 目录还有 vertical\（抖音竖屏完整版、预告、复习卡）
   和 xiaohongshu\（3:4 图文卡与 xhs-note.md）。
3. 保存竖封面、横封面，复制发布文案，登录抖音 / 小红书 / B站手动上传。
4. 用本机 Codex 做新视频：直接说“做一个词根视频”或“做一期 spect 词根”“做一个四级翻译视频”。
   智能体按 AGENTS.md 自主选题、查重、完整制作并刷新工作台。

指令判断：
- 说了具体词根、词组、试题或材料：严格按指定内容制作。
- 只说“做一个某栏目视频”：自动选择没做过的题目，复用当前完整链路直接制作。

目录分工：outputs 是交付；src、scripts、public、assets 是制作程序与素材；work 是本机临时目录（不进 git，可清空）。
新视频完成后工作台由智能体刷新，也可双击「刷新项目管理.cmd」。
