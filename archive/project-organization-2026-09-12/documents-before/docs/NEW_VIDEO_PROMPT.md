# 新制作需求入口

先决定要制作的栏目。现有长词根视频与竖屏单词原型属于两条路线；新增栏目不自动继承长视频的时长、词数和封面布局。

## 沿用成熟的词根栏目

```text
请使用本项目 build-root-word-video Skill 制作一条新的白底小黑词根视频。
主题/词根：<填写>
核心含义：<填写>
必须讲解的单词：<填写>
面向的观众/使用情境：<可选>
目标时长：<可选，按自然口播决定>
参考样片：<可选，本地路径>
结尾：<全黑 / 部分压暗 / 不压暗，可选>

先查看 README、作品清单和最近三期开头，设计适合本期的开头与语义动作。
保留本栏目的白底、微软雅黑、蓝橙色和小黑风格。默认静态透明插图加代码动画。
区分现代词义、历史词源与记忆联想，先审校再配音；避免为凑固定词数或固定秒数牺牲解释。
交付视频、1080×1440 封面、1200×900 横封面、publish-copy.md 和验收记录。
完成后更新作品清单、生产日志与 PROJECT_MEMORY.md。
```

生成与验收命令以本地 Skill 为准；有样片才做对应样片的复刻判定。没有样片时应检查本期语义、边界和手机可读性。

## 在整理基础上拓展栏目

```text
请先阅读 docs/project-audit/OPTIMIZATION.md 和 ARCHITECTURE.md。
这次优先做：<情境单词 / 易混词对比 / 互动挑战>
主题或单词：<填写>
目标观众：<填写，例如职场英语初学者>
观众看完要会什么：<一句能说的话 / 一次选词判断>
目标时长与画幅：<填写或请根据栏目提出>

先完成内容、分镜和开头节奏；明确哪些旧组件可复用、哪些要扩展。
如果使用 meme_vocab_short，先处理硬编码和缺失素材，不要只替换单词后套用 interrupt 故事。
用现有即梦/Seedream 与百炼链路完成已选方向，保留小黑角色识别，按内容设计镜头。
```
