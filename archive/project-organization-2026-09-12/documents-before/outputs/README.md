# 长视频交付目录

当前有 17 个作品交付包。完整目录、时长、发布记录与内容核对缺项统一维护在 [作品清单](../docs/project-audit/INVENTORY.md)，运行 `npm run project:inventory` 刷新。

每期目前均有 MP4、cover.png（1080×1440）、cover-landscape.png（1200×900）、publish-copy.md、兼容 douyin-copy.md，以及视频/封面技术报告。检查单存在或报告存在，不表示已人工核对或已在平台发布。

目录约定：draft / approved 用 outputs/<slug>/；published 用 outputs/<slug>发了/，并保存 release.json。目前 flect-flex、struct、tract、rupt 的目录后缀与 release 记录有冲突，详见清单；未自动修改原始记录。

竖屏 interrupt 原型位于 [output/interrupt](../output/interrupt/)，其含占位图的低清草稿不属于此处的长视频交付包。

实验与旧版本主要位于 work/，可恢复归档位于 archive/。不要仅凭名称或文件大小删除、移动运行时素材；先查分镜、音频清单与专用渲染器引用。
