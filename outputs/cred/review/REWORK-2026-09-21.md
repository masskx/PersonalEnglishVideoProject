## 返工的教学映射

八个词分别使用一套独立的三态画面：

| 词 | 画面动作 | 要讲清楚的区别 |
|---|---|---|
| credible | 核验后接过证据卡 | 有理由相信，不等于已经证实 |
| credibility | 接收方比较同一来源发来的信息 | 来源可被信任的程度/记录 |
| credulous | 不核验就接过说法并进门 | 人太容易相信别人 |
| incredulous | 听到说法后后退、拒绝卡片 | 人表示不信或怀疑 |
| incredible | 瓶口出现超预期的一簇结果 | 事件令人难以置信/惊人，不是怀疑的人 |
| credit | 交付信任凭据，借用者先获信任再偿还 | 认可、信用/赊借的关联 |
| creditable | 完成任务后获颁小奖章 | 表现值得称赞，不等于证据可信 |
| discredit | 矛盾证据出现，听众离开说法提出者 | 信誉/说法被削弱，不等于个人单纯怀疑 |

计划及最终逐词绑定见 [`../../../planning/cred-keyposes-v2.json`](../../../planning/cred-keyposes-v2.json)。24 张透明 PNG 经过素材自动 QA；白底总览和移动缩图均经过人工复核。被发现不够明确的 `discredit/result` 已单独重做。

## v1 失败的实际原因

1. 制作时把 skill 当成说明文字，没有做每词覆盖表；人工口头复核也没有检查八个词是否各有独立画面。渲染器只验证代码和媒体参数，因而错配能一路进入成片。
2. 没把“仓库内最新已接受样片”作为默认对照；之前误选旧正式输出，并错误认为没有用户提供样片就不需要逐场对照。
3. 总结内容由正文手工摘取，只留下 4 个词。旧逻辑没有把目标词集合和总结行做集合差异检查。
4. CosyVoice 指令自由描述且用了 ASCII 句点；`longanhuan` 当前要求固定指令格式和中文句号。服务返回 428 后旧脚本静默去掉 instruction 重试。
5. 音频只按文件是否存在跳过；文案或 TTS profile 改了也可能继续复用旧旁白。
6. 图片中转站偶发 HTTP 0 没有重试；参考姿态编辑串行逐张执行，失败恢复困难且批量时间长。
7. 正式 Remotion 渲染默认复制整个 `public/`，而项目当前目录有 10,347 个文件、3,614,959,409 字节（约 3.37 GiB），大部分是无关历史动画帧。

## 已落实的链路变化

- 新增 `keyposePlan` 与 `replica:preflight`。制作前的 `--plan-only` 检查逐词场景、语义、例句、三态路径与总结覆盖；素材生成及白底人工复核后完整预检图像路径、帧区间、文件完整性和视觉批准。配置了计划的项目在项目验证/正式渲染阶段 fail closed。
- 每个教学词独占一套 pose，summary 显式列八词；同义辨析对采用相反且可见的动作。
- 图像编辑可并发 1–4 项（默认 2），对临时网络、HTTP 0、429、5xx 做有限重试，等待并保留所有已完成结果；失败后可续跑未完成节点。自动白底 contact sheet 与移动缩图接入生成流程。
- TTS 检查 `longanhuan` instruction 固定格式和字符权重；默认拒绝静默降级。音频缓存根据文案 hash 和语音 profile hash 判定，必要时只重做过期段落；批任务并发完成或显式报错。
- 渲染、封面和 review stills 自动按本期 storyboard、配音、BGM、SFX、动态帧及封面插图整理最小公共素材目录。3.37 GiB 全树中，最终 `cred` 渲染仅复制 45 个引用文件、30.1 MiB（约减少 99%）；随渲染附带的双封面也复用了这份素材目录。
- `validateProject` 现在在浏览器渲染前同时检查语速上限和由 manifest 预测的旁白覆盖空档。第一轮技术渲染实际抓到 examples-in-context 提前结束 1.546 秒；补充有教学价值的对比句后语速为 1.119 倍，项目预检与第二轮严格媒体验收均通过。
- 增加 `replica:keyposes:review`：按 keyposePlan 从最终 MP4 一次解码 32 个切点前后帧，自动生成完整/移动接触表。增加移动缩图自动接触表，集中检查 360px 观看效果。
- 样片抽帧工具将均匀抽样的末点从容器尾部留出 0.1 秒，避开 `format.duration` 和最后可解码视频 PTS 不一致造成的空帧。
- 总制作规则和词根 Skill 明确规定：先找最新已接受的本地系列样片；“Skill 有步骤”不算过门，所有可以数据化的映射必须先过脚本门槛。
