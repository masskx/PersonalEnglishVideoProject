# press reference comparison

参考：`outputs/press/press.mp4`（1920×1080、30fps、172.667 秒）；候选：`outputs/spect/spect.mp4`（1920×1080、30fps、117.900 秒）。`comparison.json` 与 `contact-sheet.png` 使用 0.5、8、16、24、32、40、48、56、64、72、80、88、96、104、112、115.8 秒的 16 个安全时间点生成。

## 一致点

- 两条片均为纯白主画布、Microsoft YaHei、深蓝 `#041FA0` / 橙色 `#E85810`，右上角保持系列进度标签。
- 结构都遵循“动作钩子 → 方向/词族图 → 单词卡 → 例句 → 总结表 → 全黑收尾”。
- 小黑动作是唯一插图主体；箭头、径向图、例句、表格和字幕由代码绘制，避免把文字交给模型生成。
- 同时间点抽帧显示相同的留白、安全区、层级和淡入淡出观感；候选在 117.3 秒后保持白底直至 0.5 秒压黑，未出现提前黑帧或白闪。

## 有意差异

- press 的主题是 `press = press down`，候选是 `spect = look`；因此 press 的印刷/媒体桥段和候选的观察镜头、前缀径向图不做内容强行对齐。
- press 为 172.667 秒、较长词族章节；候选为 117.900 秒、8 个指定词，时长差是用户给定 90–120 秒目标的有意压缩，而不是渲染缺失。
- 对比仅用于系列风格、画布和收尾验证，不把跨主题的绝对秒数当成语义镜头匹配。
