# FLECT / FLEX = BEND / 弯曲

本集为 1920×1080、30fps、112 秒白底小黑词根讲解视频，结尾 0.7 秒部分压暗至 70%。

核心记忆钩子：把 `flect / flex` 想成小黑手里的一根橙色软杆；先看它向哪里弯、能不能弯，再还原单词含义。

八词：`reflect, reflection, deflect, inflect, flexible, flexibility, reflex, inflexible`。
