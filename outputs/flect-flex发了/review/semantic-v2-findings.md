# FLECT / FLEX 语义道具动态版复核

- 对比图 `semantic-v2-before-after.png` 每组左侧为改版前，右侧为语义道具动态版。
- `reflect` 增加入射、镜面接触和折返三个阶段；光线与现有镜面/小黑动作相接。
- `reflection` 不复用移动小点模板，改用镜框绘制、返回路径和三层倒影扩散。
- `deflect` 使用小球直线接近、挡板碰撞、冲击线和改变方向后的斜向轨迹。
- `inflect` 使用基线、声调波形绘制和游标运动，表达声音高低发生弯曲。
- `flexible` 使用双障碍、软条绕行和沿路径运动，表达“能弯所以能适应”。
- `flexibility` 使用三条不同曲线的连续形态接管，表达随条件反复调整的性质。
- `reflex` 使用弹簧压缩、短暂停顿和快速回弹，运动机制与路径绘制明显不同。
- `inflexible` 使用双向施力、刚杆微震、红色否定结果，明确表现受力但不弯。
- 七个逐词边界加入 28 帧橙线接力；边界 `-3/+3` 草稿抽帧未发现穿过正文、字幕、
  假拼词、双前缀或整页白闪。
- 小黑始终保留在每个核心教学场景并承担动作语义；代码道具为动作延伸，没有替代小黑。
- 正式成片保持 1920×1080、30fps、112 秒、原旁白/字幕/音乐和结尾压暗策略。
