# Port comparison findings

## Scope

用户未提供样片，因此没有逐镜复刻基准。本包用已验收的 `outputs/ject/ject.mp4` 作为当前系列风格参照，并在相同绝对白底教学语法下对 `port.mp4` 取 16 个安全时间点；这不是逐镜内容相似度声明。

## Observations

- 两条视频都保持纯白画布、Microsoft YaHei、深蓝主层级和橙色当前关系；`port` 的根词、路线图、箭头、例句和开放表格均采用同一系列阅读顺序。
- `port` 使用 12 个连续场景和持续根词徽标；对照片 `ject` 为 11 个场景。由于本集多出 `portable / porter / deport` 三个词族节点，时长与章节数是有意差异。
- `port` 的小黑在每个词场景执行搬进、搬出、横过、下托、带回、携带、拉车、带离动作；两张代码 fallback 仍保留同一黑线、留白与橙色路径语言。
- 对比帧未发现黑色提前闪现、彩色转场、字幕越过下安全带或总结提前出现。末帧为配置的全黑；倒数第二个抽帧呈单调灰阶淡黑，符合 18 帧尾部规则。
- 不同点均属主题内容差异：`ject` 展示投掷方向及重音，`port` 展示运输路线和 `-able/-er` 后缀；未做未经用户批准的样片内容替换。

## Decision

Series-style comparison accepted. Exact sample alignment is not claimed because no reference was supplied; the contact sheet is retained as visual evidence for palette, whitespace, typography, stage continuity, and ending behavior.
