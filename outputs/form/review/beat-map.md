# FORM beat map

| 时间 | 场景 | 教学与画面 |
| --- | --- | --- |
| 0–8s | Hook | `FORM = SHAPE / 形状；形成`；小黑把软团推进橙色模具。 |
| 8–18s | 方向图 | 代码径向图解释结果、进入、重新、转变、一致、破坏。 |
| 18–26.5s | formation | `form + -ation`；小黑把零件组成稳定结构。 |
| 26.5–35s | inform | `in- + form`；小黑把信息送进头脑，让认识形成。 |
| 35–43.5s | reform | `re- + form`；小黑把旧形重新塑造。 |
| 43.5–52s | transform | `trans- + form`；圆团经机器成为棱形。 |
| 52–60.5s | conform | `con- + form`；小黑把异形压进共同模具。 |
| 60.5–69s | deform | `de- + form`；小黑拉坏原有形状。 |
| 69–77.5s | uniform | `uni- + form`；一个模具做出相同形制。 |
| 77.5–86s | formula | `form + -ula`；固定材料与模具得到可重复结果。 |
| 86–96s | 例句 | 三句代码打字动画，橙色突出 form 词族。 |
| 96–112s | 总结 | 八词显式总结表；最后 0.7s 黑色遮罩到 70%。 |

所有场景为 `#FFFFFF`，文字使用系统 Microsoft YaHei，教学色为 `#041FA0` / `#E85810`；字幕位于镜头变换之外。
