# FORM = SHAPE / 形状；形成

本集为 1920×1080、30fps、112 秒白底小黑词根讲解视频，结尾 0.7 秒部分压暗至 70%。

核心记忆钩子：把 `form` 想成小黑手里的橙色模具；前缀决定“怎么塑形”，后缀决定形成的结果或方法。

八词：`formation, inform, reform, transform, conform, deform, uniform, formula`。

## 交付

- `form.mp4`：正式 H.264/AAC 成片，含连续背景音乐、旁白、字幕与音效。
- `cover.png`：1080×1440 抖音竖版封面。
- `cover-landscape.png`：1200×900 小红书横版封面。
- `publish-copy.md` / `douyin-copy.md`：发布文案。
- `beat-map.md`：逐场文案与视觉节拍。
- `comparison/`、`comparison-findings.md`：与 Press 系列样片的 16 对抽帧和书面复核。
- `review-stills/`、`midpoints-contact-sheet.png`、`boundaries-contact-sheet.png`：中点与边界抽帧。
- `render-report.json`、`cover-report.json`、`cover-landscape-report.json`、`content-qa.md`：验收报告。

最终媒体门禁：3360 帧，112.000 秒时间轴，1920×1080，30fps，音频峰值 -2.98 dBFS；9/9 RGBA 插图残绿 0%；白底、字幕安全区和结尾部分压暗通过。
