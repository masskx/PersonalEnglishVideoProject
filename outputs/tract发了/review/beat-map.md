# TRACT = PULL / 拉，拖：节拍表

| 时间 | 场景 | 教学动作 |
|---|---|---|
| 0–8s | 钩子 | 小黑拉橙色牵引绳；建立 `tract = pull` |
| 8–18s | 方向地图 | 代码绘制六向前缀辐射图 |
| 18–26.5s | attract | `at- 向 + tract 拉` → 吸引 |
| 26.5–35s | distract | `dis- 分开 + tract 拉` → 分心 |
| 35–43.5s | extract | `ex- 向外 + tract 拉` → 提取 |
| 43.5–52s | contract | `con- 一起 + tract 拉` → 收缩；合同 |
| 52–60.5s | subtract | 从下面拉走 → 减去 |
| 60.5–69s | retract | 往回拉 → 缩回；撤回 |
| 69–77.5s | tractor | 执行拉拽的机器 → 拖拉机 |
| 77.5–86s | traction | 拉的作用/抓地力 → 牵引力；附着力 |
| 86–96s | 例句 | attract / distract / extract / contract |
| 96–112s | 总结 | 八词清单；最后 0.5 秒全黑 |
