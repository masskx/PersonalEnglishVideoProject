# TRACT = PULL / 拉，拖

112 秒白底小黑词根讲解视频。讲解 8 个词：
`attract, distract, extract, contract, subtract, retract, tractor, traction`。

记忆钩子：把 `tract` 想成小黑手里的橙色牵引绳；前缀决定绳子往哪里拉，后缀决定“拉”的人、机器或作用。

- `cover-landscape.png`：1200×900 横版封面

## 质检结论

最终视频的钩子与 8 个单词均使用白底图生视频动态小黑，不做 Alpha 抠像。视频 3360 帧完整解码，峰值 -2.89 dBFS，旁白覆盖空窗和未解释长静音均为 0。节目背景为纯白；第 3344 帧为白、第 3352 帧为中灰、第 3359 帧为全黑。两版封面均通过尺寸、不透明、白角和 8 词完整性检查。
