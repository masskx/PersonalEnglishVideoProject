# VIS / VID = SEE

白底小黑词根讲解成片。用户输入中的 `-vidt` 已校正为常见词根形态 `vid`，与 `vis` 作为同源变体共同讲解。

## 交付文件

- `vis-vid.mp4`：1920×1080，30 fps，118.500 秒，结尾 0.500 秒全黑。
- `cover.png` / `cover-landscape.png`：竖版与横版封面。
- `douyin-copy.md`：同步发布文案。
- `render-report.json`：最终媒体与音频检查。
- `comparison/`：与 `outputs/press/press.mp4` 的 14 组配对帧。
- `review-stills/`、`final-encoded-contact-sheet.png`：源渲染与最终编码抽帧。
- `asset-contact-sheet.png`：透明小黑插画总览。
- `comparison-findings.md`：样片对比结论。

## 教学与验证

`vis / vid = see（看见）`。记忆钩子把 `vid` 当作“正在看见的动作”，把 `vis` 当作“看见后形成的视觉/画面”。讲解 `vision, visible, video, visual, evidence, evident, visit, revise`。

最终视频 3555 帧，H.264 CFR 30 fps，AAC 双声道 48 kHz；峰值 -2.79 dBFS，旁白覆盖无缺口，无未解释长静音，最终黑场通过。9/9 插画为 2848×1600 RGBA，绿色残留均为 0.000%。两版封面通过检查。
