# STRUCT = BUILD / 建造；搭建

本集为 1920×1080、30fps、112 秒白底小黑词根讲解视频，结尾 0.7 秒部分压暗至 70%。

核心记忆钩子：把 `struct` 想成小黑手里的橙色积木骨架；先看“怎么搭”，再判断是在共同建造、重新建造、拆掉，还是挡住建造。

八词：`construct, construction, structure, instruct, instruction, reconstruct, destruct, obstruct`。

## 交付

- `struct.mp4`：正式 H.264/AAC 成片，含配音、背景音乐、音效、动画与字幕。
- `cover.png`：1080×1440 抖音竖版封面。
- `cover-landscape.png`：1200×900 横版封面。
- `publish-copy.md` / `douyin-copy.md`：发布文案。
- `beat-map.md`：逐场文案与视觉节拍。
- `comparison/`、`comparison-findings.md`：与 Press 系列样片的 16 对抽帧及复核结论。
- `review-stills/`、`midpoints-contact-sheet.png`、`boundaries-contact-sheet.png`：中点与边界抽帧。
- `asset-contact-sheet.png`：9 张透明小黑插图总览。
- `render-report.json`、`cover-report.json`、`cover-landscape-report.json`、`content-qa.md`：验收报告。

最终媒体门禁：3360 帧、112.000 秒时间轴、1920×1080、30fps，音频峰值 -2.87 dBFS，0 个允许长静音窗口；9/9 RGBA 插图残绿 0%，白底、字幕安全区和结尾部分压暗通过。
