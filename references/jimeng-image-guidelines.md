# 即梦竖屏剧情关键帧规范

用于 `meme_vocab_short` 的本地素材生成与替换。每个镜头只生成一张独立的 `9:16` 关键帧。

每条提示词必须明确写出：

- 人物：角色外形和跨镜头一致性；
- 动作：角色正在做什么；
- 冲突：谁和谁、什么结果发生冲突；
- 荒诞元素：把抽象词义变成可见的异常行为；
- 情绪：冷静、尴尬、慌张或夸张惊讶；
- 构图：主体、前景、背景和视觉重心；
- 主体位置：主体必须避开底部字幕与抖音 UI 区；
- 字幕安全区：底部至少 22% 留白；
- 画幅：明确 `9:16 vertical`；
- 负面约束：`no text, no watermark, no logo`；
- 角色一致性：黑色实心小黑、白点眼、细腿、冷静表情。

图片不负责承载英文单词、音标或字幕；所有文字由 Remotion 绘制。图片不存在时必须使用明显标记为 `PLACEHOLDER` 的素材，并在 `assets-manifest.json` 和 `qa-report.md` 中列为待替换项。
