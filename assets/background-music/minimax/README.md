# MiniMax 背景音乐素材库

这个目录保存 MiniMax 中国站生成的原始音乐和筛选记录，不直接作为 Remotion 运行时路径。

目录约定：

- `candidates/`：网站下载的原始候选，文件名保留批次和版本。
- `reviews/`：响度、节奏、循环点和人工试听记录。
- `accepted/`：通过手机外放、耳机、旁白混音与循环检查的母带。

最终采用的系列母带复制到：

`public/assets/music/root-word-series-bgm.mp3`

当前目标：104–112 BPM，明亮、轻快、有四小节记忆动机，纯音乐，无人声、无歌词、无音频水印。旋律要能被记住，但旁白期间不能抢中文和英文单词。

## MiniMax Music 3.0 首轮提示词

```text
抖音英语知识类短视频的原创纯音乐背景。108 BPM，明亮、轻快、聪明、有一点俏皮和洗脑感。用清脆木琴、短促拨弦、轻盈电钢琴、圆润贝斯和干净的轻鼓点，写一个四小节就能记住的短旋律动机，每八小节做一次小变化。开头一秒内进入节拍，段落稳定，适合连续中文讲解和英文单词朗读。不要大起大落，不要情绪煽情，不要突然停顿。整体现代、精致、干净，像高完成度的知识类短视频配乐。纯音乐，无人声、无歌词、无人声切片、无口哨、无喊声。结尾便于循环衔接。
```

备用方向：把 BPM 改为 104 或 112，并分别强调“木质敲击感”和“轻电子弹跳感”。
