# 画面留白优化报告

## 方法

- 对全部 15 条正式成片在 6、18、30、42、54、66、78、90、102 秒抽帧。
- 使用同一套 3×3 接触表和阈值统计非白像素占比。
- `ject` 保持不变，作为系列中空间组织最成熟的参考。
- 占比只用于发现异常留白，不作为机械填满画面的目标。

## 改动

- 新式逐词页：小黑动作区扩大约 25%，构词与义项向中部收拢。
- 新式逐词页：加入代码绘制的“拆词 → 看动作 → 得词义”教学轨道。
- 旧式插图页：原插图保守放大 14%，不改变原有叙事结构。
- 旧式纯文字页：文字轻微放大，并加入低对比词根水印。
- 开场、转场、例句和总结页保留原有呼吸感，不机械加内容。

## 结论

新式连续舞台已从“主体偏小造成的空”提升为有明确阅读顺序的结构化留白。
旧式项目仍保持较轻的画面密度，但核心插图和文字关系更清晰；其中 `reg` 仍是系列
最疏的项目，不过纯文字页已有词根水印支撑，不建议继续用无关图标填满。
